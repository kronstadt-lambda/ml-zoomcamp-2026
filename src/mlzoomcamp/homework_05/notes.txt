==================================================
APRENDIZAJES
==================================================

1. Un artefacto serializado con `pickle` puede cargarse para realizar
   inferencia sin reentrenar el modelo; el pipeline encapsula las
   transformaciones y el modelo entrenado.

2. La normalización de datos sigue siendo importante antes de inferir:
   `model.py` convierte tipos e imputa valores faltantes antes de enviar
   el registro al pipeline.

3. FastAPI permite exponer la inferencia como un servicio HTTP mediante
   endpoints como `/health` y `/predict`; Uvicorn ejecuta ese servicio.

4. El endpoint `/health` es útil para confirmar disponibilidad y
   verificar qué artefacto del modelo está utilizando el servicio
   mediante su checksum SHA-256.

5. Docker permite empaquetar Python, dependencias bloqueadas, el modelo
   congelado y la API en una imagen reproducible.

6. Ejecutar la misma predicción localmente, mediante FastAPI y dentro
   del contenedor permite comprobar consistencia entre desarrollo y
   despliegue.
