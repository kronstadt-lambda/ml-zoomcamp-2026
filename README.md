# Machine Learning Zoomcamp 2026

Personal learning repository for the [Machine Learning Zoomcamp 2026](https://github.com/DataTalksClub/machine-learning-zoomcamp/tree/main/cohorts/2026) by DataTalks.Club.

## Project structure

```text
src/mlzoomcamp/
├── config.py
└── homework_XX/
    ├── main.py
    └── README.md
data/
test/
```

The project uses Python, [`uv`](https://docs.astral.sh/uv/), and a `src` layout. Each completed homework is documented in its own directory; this README will link to it once its documentation is authorized and available.
